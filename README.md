# weather-data-analysis-system

## About the Project

The **Weather Data Analysis System** is a web-based project used to analyze weather data.

Users can upload a **CSV file** containing weather information such as temperature, humidity, rainfall, date, and location.

The system processes the data and displays the results in the form of **tables and graphs**.

## Technologies Used

* Python
* Flask
* Pandas
* NumPy
* Matplotlib
* MySQL
* HTML
* CSS

## Features

* Upload weather data using CSV
* Check and validate data
* Find duplicate records
* Store data in MySQL
* Calculate weather statistics
* Perform monthly analysis
* Display temperature, humidity, and rainfall graphs
* Show results on a web dashboard

## How It Works

```text
Upload CSV
    ↓
Validate Data
    ↓
Store Data in MySQL
    ↓
Analyze Data
    ↓
Generate Graphs
    ↓
Display Results
```
